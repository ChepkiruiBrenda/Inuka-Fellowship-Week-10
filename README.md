# Equipment Failure Risk Monitor

A live prediction dashboard that tells you which assets are at risk of failure — and exactly why.

Enter sensor readings, click a button, and get an instant failure probability score with a plain-English explanation of what is driving the risk.

---

## What it does

- Scores any asset from 0% to 100% failure probability using a trained XGBoost model
- Shows a SHAP chart explaining which sensor triggered the alert
- Three risk tiers: Low (green), Medium (amber), High (red)
- Tells the operator exactly what action to take

---

## Prerequisites

- Python 3.9 or higher
- pip (comes with Python)
- The CSV file: `synthetic_predictive_maintenance_data.csv`

---

## Setup (one-time)

**Step 1 — Install packages**

Open a terminal in the `week10_ops_tool` folder and run:
```
pip install -r requirements.txt
```

**Step 2 — Copy your data file**

Copy `synthetic_predictive_maintenance_data.csv` into the `week10_ops_tool` folder.

**Step 3 — Train and save the model**

Run this once to generate the model files:
```
python save_model.py
```

You will see this when it finishes:
```
✅ Saved:
   xgb_model.joblib
   feature_cols.joblib
```

Both files will appear in your folder. You only need to do this once.

---

## Run the dashboard

```
streamlit run app.py
```

Your browser opens automatically at `http://localhost:8501`

---

## How to use it

1. Type an Asset ID in the sidebar (e.g. `PUMP-07`)
2. Set the sensor sliders to the live readings for that asset
3. Click **Run Risk Assessment**
4. Read the risk score and the SHAP chart

## Model performance

| Metric | Value |
|--------|-------|
| CV ROC-AUC | 0.9994 |
| Test Recall (failures caught) | 95.8% — 23 of 24 |
| Test Precision | 54.8% |
| Fleet failure rate | 2.0% (49:1 imbalance handled with SMOTE) |

Top 3 failure drivers (from SHAP analysis):
1. `vib_torque_stress` — vibration × torque (compound mechanical stress)
2. `temp_speed_ratio` — temperature ÷ rotational speed (thermal efficiency)
3. `vibration` — raw oscillation reading
